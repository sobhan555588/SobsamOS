# SobsamOS v0.1

Simple Command Line Operating System written in Assembly.

## About

SobsamOS is a small 16-bit CLI operating system.
It boots directly from BIOS and provides a simple command line interface.

## Features

- BIOS boot support
- 16-bit Assembly
- Simple CLI
- Keyboard input
- Text display
- Basic commands

## Commands
h - help
v - version
a - about
c - clear screen
r - reboot
s - shutdown


## Run

Use VirtualBox or another emulator:

- Create a new machine
- Attach `SobsamOS.iso` as a boot disk
- Start the machine
